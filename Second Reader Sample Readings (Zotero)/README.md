# Second Reader Sample Readings (Zotero)

This folder is a Zotero collection of the SR 101 readings, exported from Zotero with **Export Collection… → Zotero RDF** and **Export Files** checked.

- `Second Reader Sample Readings (Zotero).rdf` has the reference for each reading and points to its files under `files/`.
- `files/` holds the PDFs, one folder per reading. Some readings also have a snapshot of the article's web page. Every reading was chosen because its license allows the PDF to be shared publicly (see `SOURCES.md`).

## Importing into Zotero

Install Better BibTeX first (Part 3 of the setup guide).

1. In Zotero, choose **File → Import…** → **A file (BibTeX, RIS, Zotero RDF, etc.)** → pick `Second Reader Sample Readings (Zotero).rdf`. Leave it in this folder, next to `files/`.
2. When asked about files, choose **Copy files to the Zotero storage folder**.
3. Check that each item has a PDF under it. If one doesn't, drag that PDF from `files/` onto the item.

The literature notes in the vault are already made and carry each reading's citation key (`lee2025`, `gerlich2025`, `zhai2024`, `jose2025`, `stadler2024`, `doshi2024`, `bucinca2021`, `sharma2025`). Each key is also written in the item's Extra field as `Citation Key: …`, which tells Better BibTeX to keep it. Don't rename the items or change their citation keys.

## Giving the collection to other people

The whole vault, including this folder, can be shared as one download. To share just the readings, zip this folder. People unzip it and follow "Importing into Zotero" above.

All the readings are licensed CC BY, so they can be shared and reused with attribution.
