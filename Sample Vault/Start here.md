# Start here

This is a starter vault for the Second Reader note system. It comes with a sample six-week course, SR 101: Thinking With Machines, so you can try the whole workflow on real readings before using it for your own course.

## Folders

| Folder | What goes in it |
|---|---|
| `Classes/` | One folder per course and term, with the syllabus and a `Meeting notes/` folder (one note per class meeting) |
| `Literature notes/` | One note per reading, made by Second Reader's import from Zotero |
| `Permanent notes/` | One idea per note, in your own words. Made by checking a candidate box in a literature note |
| `Synthesis notes/` | What you now think about a topic, drawing on several permanent notes |
| `Project notes/` | The argument and evidence for something you're writing |
| `Templates/` | Templates for each kind of note |
| `Attachments/` | Images from your Zotero highlights and screenshots |
| `Uploads/` | Zips made by the syllabus's "Package my Week N" links |

## Setting up

1. Open this folder in Obsidian with **Open folder as vault**. When asked, trust the author and turn on community plugins. Second Reader is already included.
2. Open Settings → Second Reader and click the download button next to **PDF Utility**.
3. Install Zotero 7 and the Better BibTeX plugin, and turn on Zotero's "Allow other applications to communicate with Zotero" setting.
4. Import the readings into Zotero (see the README in `Readings for Zotero/`).
5. Install the **Dataview** community plugin if you want the lists in synthesis and project notes to fill themselves in.

## Trying it

1. Open [[Syllabus - student copy]] and pick a Week 1 reading.
2. Run **Second Reader: Literature Note** from the command palette and choose that reading. The note appears in `Literature notes/`.
3. Click **open pdf** in the syllabus, highlight a few passages in Zotero, then click the highlighter button at the top right of the note.
4. Write a permanent note candidate in your own words and check its box.
5. Open [[Week 1 - What people use AI assistants for]] and add your class notes.

The full setup guide is in the plugin repository: https://github.com/kevinmil54/second-reader-obsidian-promote/blob/main/STUDENT-SETUP-GUIDE.md
