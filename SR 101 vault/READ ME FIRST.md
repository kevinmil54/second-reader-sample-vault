# SR 101 starter vault

This folder is a ready-made Obsidian vault for the Second Reader note system, with a six-week sample course on how people interact with large language models.

1. Unzip it somewhere on your computer (not inside another vault).
2. Open Obsidian, choose "Open folder as vault", and select the `SR 101 vault` folder.
3. Obsidian will ask whether you trust the author of this vault. Choose "Trust author and enable plugins". If it does not ask, go to Settings > Community plugins and choose "Turn on community plugins". Second Reader is already installed.
4. In Settings > Community plugins > Browse, install and enable **Dataview**, **Style Settings** and **Templater**. Their settings are already in the vault. Dataview fills in the lists in synthesis and project notes, Style Settings gives the AnuPpuccin theme its colors and fonts, and Templater runs the class meeting template.
5. Open Settings > Second Reader and click the download button next to "PDF Utility".
6. Install Zotero 7 with the Better BibTeX add-on (Part 3 of `STUDENT SETUP GUIDE - SR 101.md`).
7. Import the course readings into Zotero (the `README.md` in the `SR 101 Zotero readings` folder).
8. Start at `Classes/SR 101 Sample term`: the syllabus, the course home note, and one meeting note per class.

## What is in the folders

| Folder | What it holds |
|---|---|
| Classes | One folder per course with the syllabus, a course home note, and one meeting note per class |
| Literature notes | One note per reading, made by Second Reader's import (empty to start) |
| Permanent notes | Your own ideas, one idea per note (empty) |
| Synthesis notes | Where you pull several ideas together (empty) |
| Projects | Your project work (empty) |
| Inbox | New notes land here until you file them |
| Attachments | Images from your Zotero highlights, and screenshots |
| Templates | Literature note, permanent note, synthesis note, project and class meeting templates |
| Uploads | Zips made by the syllabus's "Package my Week N" links |

The headings use Source Serif Pro if it's installed on your computer; otherwise Obsidian uses a similar font.
