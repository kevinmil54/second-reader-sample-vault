# SR 101 starter vault

This folder (`second-reader-sample-vault`) is a ready-made Obsidian vault for the Second Reader note system, with a four-week sample course on how people interact with large language models.

1. Unzip it somewhere on your computer (not inside another vault).
2. Open Obsidian, choose "Open folder as vault", and select the `second-reader-sample-vault` folder itself.
3. Obsidian will ask whether you trust the author of this vault. Choose "Trust author and enable plugins". If it does not ask, go to Settings > Community plugins and choose "Turn on community plugins". Second Reader, Dataview, Templater and Style Settings are already installed from Obsidian's community plugin directory, along with the AnuPpuccin theme and its settings. Obsidian keeps them up to date like any other community plugin.
4. Open Settings > Second Reader and click the download button next to "PDF Utility".
5. Install Zotero 7 with the Better BibTeX add-on (Part 3 of `STUDENT SETUP GUIDE - SR 101.md`).
6. Import the course readings into Zotero (the `README.md` in the `Second Reader Sample Readings (Zotero)` folder).
7. Start at `Classes/SR 101 example/Winter 2027`: the syllabus, the course home note, and one meeting note per class. The `Planning` folder there has an instructor's planning note for each class. Each reading's literature note is already there; open it from the syllabus.

## What is in the folders

| Folder | What it holds |
|---|---|
| Classes | One folder per course with the syllabus, a course home note, and one meeting note per class |
| Literature notes | One note per reading, ready for your notes, each linked to your own copy of the paper in Zotero |
| Authors | One note per author, with a short bio and links; add a photo if you like |
| Permanent notes | Your own ideas, one idea per note (empty) |
| Synthesis notes | Where you pull several ideas together (empty) |
| Projects | Your project work (empty) |
| Inbox | New notes land here until you file them |
| Images | Figures from the papers, images from your Zotero highlights, and screenshots |
| Templates | Literature note, permanent note, synthesis note, project and class meeting templates |
| Uploads | Zips made by the syllabus's "Package my Week N" links |
| Second Reader Sample Readings (Zotero) | The readings, ready to import into Zotero |

The headings use Source Serif Pro if it's installed on your computer; otherwise Obsidian uses a similar font.
